#  Hangman Game — CodeAlpha Internship

A simple text-based Hangman Game developed in Python as part of the CodeAlpha Python Programming Internship.

##  Project Overview

The player has to guess a randomly selected word one letter at a time.

The game contains five predefined words and allows the player a maximum of six incorrect guesses.

##  Features

- Randomly selects a word from a list of 5 predefined words
- Allows the player to guess one letter at a time
- Maximum of 6 incorrect guesses
- Displays correctly guessed letters
- Detects incorrect guesses
- Prevents repeated guesses
- Validates user input
- Displays win and game-over messages
- Runs completely in the terminal

##  Technologies Used

- Python 3
- Random module
- Lists
- Strings
- If-else statements
- While loop
- For loop
- User input
