# 📈 Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker that allows users to add stocks, calculate their individual investments, calculate the total portfolio investment, and save the portfolio details to a text file.

## 🚀 Features

- Add multiple stocks
- Store stock prices using a Python dictionary
- Enter stock quantity
- Calculate individual stock investment
- Calculate total portfolio investment
- Validate stock symbols
- Handle invalid quantities
- Handle invalid user input
- Save portfolio details to a `.txt` file

## 🛠️ Technologies Used

- Python
- Dictionary
- Functions
- Lists
- File Handling
- Exception Handling
